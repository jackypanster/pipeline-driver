# C5 — external installer steps (appended after review-01)

Review-01 P1: `setup_preflight` / `setup_sources` / `setup_skills` / `setup_dashboard_build` shipped as
`:` no-ops, so PRD Scope steps 1–4a did nothing while the suite went green. Implement them, honest-degrade
per ADR 0002 (never fake success — print `s_miss` remediation + increment `setup_bad`).

Required behavior (bound by `test/setup-external.sh`, all hermetic — no network/pkg work in the test):

1. **preflight (`SETUP_DO_DEPS`)** — check the wizard's system deps (git/node/npm/gh/jq/fzf/orca).
   Missing ⇒ `s_miss` with the exact install command + non-zero exit. **The public toggle is
   `SETUP_DO_DEPS`** (review-01 finding 6 — the code checked `SETUP_DO_PREFLIGHT`); `SETUP_DO_DEPS=0`
   must actually skip the step.
2. **sources** — clone missing / (opt-in `SETUP_REFRESH_SOURCES=1`) `git fetch && reset --hard` present
   source repos. A missing source with refresh off ⇒ `s_miss` (do not silently pass).
3. **skills** — `cp -r $SETUP_PIPELINE_REPO/skills/pipeline-* $SETUP_SKILLS_DIR`; then `ln -sfn` attach
   the runtimes named in `SETUP_RUNTIMES` (empty ⇒ canonical copy only). The canonical copy must happen
   (not a no-op).
4. **dashboard** — `npm ci && npm run build` + `npm link` in `$SETUP_DASHBOARD_REPO`; absent repo or
   missing npm ⇒ `s_miss` with the build command.

Impl-paths = `drive.sh` only (shared with card 01; both land on `feat/drive-setup`). Do NOT touch
spec-paths. Interactive fzf runtime picker / real network are coder-owned (review-reads).
