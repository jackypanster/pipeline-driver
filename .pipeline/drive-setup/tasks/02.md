# C2 — defaults generation + seam

Implement step 5 (`setup_defaults`) and the four `ask_*` helpers it depends on (arch.md §non-interactive
interface, ADR 0003):

- `ask_value/ask_confirm/ask_choice/ask_multi` resolve `SETUP_<KEY>` env → default (headless) →
  fzf/`read -e -i` (TTY). ONE code path; `SETUP_YES=1` forces headless.
- `setup_defaults` writes `$DEFAULTS` (drive.sh:62 — the `${DRIVE_DEFAULTS:-…}` path; `mkdir -p` its
  dir) from the drive.defaults.example template, filling: `IMPL_TRANSPORT` `IMPL_SLASH_CMD` `IMPL_MODEL`
  `REVIEW_TERMINAL_TITLE` `REVIEW_SLASH_CMD` `YOLO` `BOARD_OUT` + the sibling/skills paths.
- `REVIEW_SLASH_CMD` MUST be emitted single-quoted: `REVIEW_SLASH_CMD='$pipeline-review'`
  (drive.defaults.example:80 — unquoted, bash expands `$pipeline` to empty).
- Overwrite policy: render to a string; identical to the existing file ⇒ no write, no `.bak`; different
  ⇒ `cp` existing to `$DEFAULTS.bak` then write.
